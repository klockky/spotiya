Добавлен официальный Spotify Soloist как основной Spotify backend. Librespot остаётся доступен для явного выбора; автоматического перехода на librespot или PlayPlay нет.

### Установка Soloist

В TUI откройте дополнения (`a`), выберите Spotify Soloist и нажмите Enter, либо выполните:

```sh
spotiya addon install soloist
/data/opt/solo/set-key.sh
spotiya backend soloist
spotiya restart
```

Нужен личный Soloist API key от действующего Premium-аккаунта: https://developer.spotify.com/dashboard/soloist.
Официальный клиент скачивается самой станцией напрямую с серверов Spotify. В этом релизе распространяется только наш пакет совместимости, без бинарника Soloist и без учётных данных.

### Изменения

- Управление Soloist через локальный API: Spotify Connect, кнопки, пауза, переключение треков и единая громкость.
- Спектр Soloist на дисплее Мини 2, включение/выключение клавишей `e` в TUI. В Spotiya передаются только уровни частотных полос.
- Установка, обновление и удаление Soloist через экран дополнений и CLI; проверка архивов, сохранение ключа и откат при ошибке замены.
- Исправлены зависание ARM32-клиента на ядре Мини 2, двойное приглушение и ошибка освобождения памяти в аудиослое.

### При обновлении

По умолчанию выбран Soloist. Старые данные librespot автоматически не используются: установите Soloist и задайте свой ключ. Для осознанного возврата к прежнему backend: `spotiya backend librespot`, затем `spotiya restart`.
После обновления дополнения Soloist выполните `spotiya retry`. Официальные сборки имеют ограниченный срок действия; дополнение скачивает актуальную сборку Spotify.

### Ограничения

Интеграция проверена на Мини 2. Текстовый/голосовой поиск через Soloist пока не реализован; совместный аудиовывод с другими дополнениями полностью не проверен.
Минимальный лимит кэша Soloist — 100 МБ, что больше раздела данных Мини 2. Постоянная работа требует контроля свободного места; ограничение кэша для маленькой флеш-памяти пока не решено.

Локально пройдены 130 Rust-тестов, clippy, Python-тесты и проверки аудиослоя на Мини 2. Подтверждены звук, пауза, переподключение и спектр. Установщик проверен с настоящей загрузкой Spotify, повторной установкой и нехваткой места.
