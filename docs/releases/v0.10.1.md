Spotiya 0.10.1 упрощает настройку официального Spotify Soloist: после установки дополнения появляется запрос личного API-ключа со скрытым вводом.

### Изменения

- Удалены дополнение PlayPlay, его резервный путь в приёмнике, исходники декодера и сборка пакета в CI.
- После установки Soloist через CLI или TUI запрашивается API-ключ, если он ещё не сохранён. Обновление сохраняет существующий ключ.
- В TUI Enter на установленном Soloist позволяет заменить ключ; Esc отменяет ввод. Ключ не отображается на экране и сохраняется с правами `0600`.
- При запуске без интерактивного терминала установка завершается с инструкцией для последующего ввода ключа.
- README очищен от прежних инструкций и обновлён для Soloist.

### Установка и обновление

Обновить Spotiya:

```sh
spotiya update
```

Установить Soloist:

```sh
spotiya addon install soloist
spotiya backend soloist
spotiya restart
```

Ключ создаётся в [Spotify for Developers](https://developer.spotify.com/dashboard/soloist) действующим Premium-аккаунтом. Официальный клиент загружается напрямую с серверов Spotify; в релиз входит только пакет совместимости.

Для замены ключа из терминала: `/data/opt/solo/set-key.sh`, затем `spotiya retry`.
Ранее установленные файлы PlayPlay автоматически не удаляются, но новый приёмник их не использует.

### Проверка

Локально прошли 127 Rust-тестов, 29 Python-тестов и clippy. Проверены скрытый ввод, отмена с восстановлением терминала и сохранение прежнего ключа. ARM-сборка проверена на совместимость с glibc 2.23. Изменения ввода ключа на самой колонке пока не проверялись.
